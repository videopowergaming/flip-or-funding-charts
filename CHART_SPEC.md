# Chart Presentation Spec — APPROVED

Patrick signed off on this presentation on **2026-10-14** and wants the chart presented this
way **continually, going forward, until he says otherwise.** Do not change these without Patrick
asking. The page (`charts/flipor_wave2_funding.html`) is regenerated by `build.py` on every
refresh and must always contain, in this order:

1. **Header + stat cards** — campaign title, "View on Kickstarter" link, an **"As of <date · time>"**
   line, and color-coded cards: pledged (blue), % of goal (purple), backers (teal), days to go (red).

2. **Full campaign chart** — dollars pledged vs time, from the **launch day → Nov 17 deadline**.
   - **Daily** x-axis ticks: day number on the main row, month (Oct / Nov) on a second row.
   - $200,000 goal line (dashed red).
   - Colored axes: y-axis purple, x-axis teal.

3. **7-day window chart (zoomed)** — same 960×540 size.
   - Always shows a **full 7-day span** on the x-axis (e.g. Oct 13–20 at launch), **rolling forward**
     so it tracks the most recent 7 days as the campaign progresses.
   - Same goal line, colored axes, daily ticks.

4. **Data pull log** — a table with one row **per data pull**, newest first:
   **Date & time · Pledged · Change · Backers.** (Finalized by Patrick.)

5. **Update calendar** — per-day summary: end-of-day pledged, daily gain, backers, snapshots,
   and "no data (away)" rows for days the monitor wasn't running.

## Interactive hover (added 2026-10-17, Patrick signed off — keep permanently)
Both the full-campaign and 7-day charts have a cursor hover tooltip:
- Moving the cursor anywhere over the plot area (including the blue fill under the line) shows a
  tooltip next to the cursor with the **pledged $ value** and the **date/time** of that point.
- It **snaps to the nearest actual recorded snapshot** — never interpolates or guesses; every
  value shown is a real measurement.
- A vertical crosshair + marker dot pin the point on the line. Updates live as the cursor moves.
- Implemented via per-chart `data-cfg` JSON on each `<svg>` + a `.hover-capture` overlay rect +
  the `HOVER_SCRIPT` in `build.py`. Works with mouse and touch.

## Y-axis
Auto-scales to ~110% of max(goal, pledged). Fine at current levels; revisit denominations only if
funding rises substantially (Patrick's note, 2026-10-14).

## Refresh
All of the above regenerate together every time `build.py` runs (hourly monitor, or `--record`).
The page auto-reloads in the browser every 60s.
