# Flip-Or Funding Charts

A tool for generating and tracking Flip-Or funding charts and data.

## Structure

- `data/`   — source/working data (inputs and generated datasets)
- `charts/` — generated chart output (images / HTML)
- `docs/`   — project notes and reference material
- `config.json` — project configuration
- `build.py` — main script (generates charts from data)
